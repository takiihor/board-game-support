離線輸入及本機儲存

本鍵盤及主 App 不會連線或上傳輸入內容，不需要帳戶或登入。字庫隨 App 提供。設定、自訂詞語及選字學習記錄只留在裝置，用於輸入及排列候選字詞；個人學習資料排除系統備份。沒有開發者營運的雲端副本。

可選的完全取用

內置字庫不需要完全取用。啟用後，鍵盤可透過本機 App Group 與主 App 共享設定、自訂詞語及學習記錄；未啟用時，鍵盤使用自身的本機資料。雖然 iOS 的此權限也允許網路存取，本鍵盤沒有網路程式碼，不會上傳資料。

廣告、分析及追蹤

App 和鍵盤沒有廣告、分析 SDK 或追蹤服務，不會向開發者或第三方傳送個人資料或使用數據。

管理、匯出及刪除資料

你可關閉學習、使用私人輸入、在個人詞庫清除學習記錄或刪除自訂詞語。CSV 匯入及匯出由你透過系統檔案選擇器操作；如把匯出檔案存到第三方服務或傳送給別人，該服務或收件人會按其方式處理資料。刪除 App 可移除其本機資料；你另行匯出的檔案須自行刪除。

支援及平台服務

若你電郵聯絡支援，我們會使用你選擇提供的資料回覆；電郵供應商按其政策處理郵件。Apple 可能按其私隱政策處理 App Store、TestFlight 或裝置診斷資料。

本網站由 GitHub Pages 託管，GitHub 可能按其私隱聲明處理網站請求。本網站沒有廣告、分析程式或追蹤 Cookie。

Offline input and local storage

The keyboard and companion app do not connect to a network or upload typed content. No account is required. Dictionaries are bundled with the app. Preferences, custom words and learned selections remain on your device for input and candidate ranking. Personal learning data is excluded from system backup. There is no developer-operated cloud copy.

Optional Full Access

The built-in dictionary works without Full Access. Enabling it lets the keyboard share preferences, custom words and learned entries locally with the companion app through an App Group. Without it, the keyboard uses its own local data. Although this iOS permission also permits network access, this keyboard has no networking code and does not upload data.

Advertising, analytics and tracking

The app and keyboard contain no advertising, analytics SDK or tracking service. They do not transmit personal data or usage information to the developer or third parties.

Managing, exporting and deleting data

You can disable learning, use private input, clear learned entries or remove custom words. You control CSV import and export using the system file picker. If you save exported files to another service or send them to someone, that service or recipient processes them independently. Deleting the app removes its local data; you must separately delete any files you exported.

Support and platform services

If you email support, we use the information you choose to send to respond. Email providers process messages under their policies. Apple may process App Store, TestFlight or device diagnostics information under Apple’s privacy policy.

This website is hosted by GitHub Pages. GitHub may process website requests under GitHub’s privacy statement. This website has no advertising, analytics scripts or tracking cookies.
